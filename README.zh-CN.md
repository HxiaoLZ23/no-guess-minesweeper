## 怎么玩

- **电脑**：左键翻开，右键标旗。数字周围旗数已满足时，双击或中键该格，可翻开其余邻格。
- **手机**：点按翻开，长按标旗。可切换「翻开 / 标旗」，双指缩放。
- **键盘**：方向键移动，空格翻开，F 标旗，Z 撤销，H 提示。
- 打开后先在首页选择模式。练习、竞速、禅再进入下一页选择盘面。闯关和教学关卡各自有一页。

## 难度与模式

- 经典：初级、中级、高级。
- 疏雷、匀雷、密雷的雷数较少，便于练习。
- 练习先选择雷数较少的盘面，再进行经典雷数。竞速只记录经典三档和每日挑战。禅模式不计时，尺寸可自定。
- 闯关自 8×8 起，按 8×8、8×9、9×9、9×10 的顺序增大，直到 18×18。
- 教学关卡可展开完整解析。
- 练习可以使用提示、撤销和暂停。
- 竞速在倒计时后开始。无提示，不可暂停，并记录点击次数与最佳用时。
- 禅模式不计时。踩雷不结束对局。
- 复盘可暂停，并按 0.5×、1×、2×、4× 播放。

## 本地与可选云端

默认完全离线。可在设置中导出或导入进度。

若配置了同步端点，还可进行云备份和每日榜。失败不影响游玩。部署说明见 [`cloud/README.zh-CN.md`](cloud/README.zh-CN.md)。
