## 遊び方

- **パソコン**：左クリックで開く、右クリックで旗。数字の周囲の旗が揃ったら、ダブルクリックか中クリックで残りを開けます。
- **携帯電話**：タップで開く、長押しで旗。「開く / 旗」を切り替えられ、ピンチで拡大縮小します。
- **キーボード**：方向キーで移動、Space で開く、F で旗、Z で取り消し、H でヒント。
- 最初にホームでモードを選びます。練習、タイムアタック、禅は次のページで盤面を選びます。キャンペーンとレッスンはそれぞれ別のページです。

## 難易度とモード

- クラシック：初級、中級、上級。
- 疎、標準、密は地雷が少なく、練習向けです。
- 練習では地雷の少ない盤から始め、その後クラシックの地雷数に進みます。タイムアタックが記録するのはクラシック三段階とデイリーだけです。禅は時間を計らず、サイズを指定できます。
- キャンペーンは 8×8 から、8×8、8×9、9×9、9×10 の順に大きくなり、18×18 まで続きます。
- レッスンでは解説をすべて開けます。
- 練習ではヒント、取り消し、一時停止が使えます。
- タイムアタックはカウントダウン後に始まります。ヒントはなく、一時停止できません。クリック数と自己ベストを記録します。
- 禅は時間を計りません。地雷を開いても対局は終わりません。
- 再生は一時停止でき、0.5×、1×、2×、4× で再生できます。

## ローカルと任意のクラウド

既定では完全にオフラインです。設定で進捗を書き出し、読み込めます。

同期エンドポイントを設定すると、クラウドバックアップとデイリー順位表が使えます。失敗してもプレイは続きます。手順は [`cloud/README.md`](cloud/README.md) を参照してください。

## 開始

- `index.html` を開くか、上のリンクを使います。
- PWA としてインストールし、オフラインでも使えます。

リアルタイム対戦はありません。時間を比べるには共有リンクを使います。
