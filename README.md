# 无猜扫雷

打开就能玩的无猜扫雷。每一局都由约束求解**直接构造**出一条完整推理链：首击及其周围没有雷，并且独立求解器能只靠可见数字走完全程。不是先随机埋雷再反复丢弃。

## 启动

- 双击 `index.html`（纯本地，无需安装）
- 或双击 `start.bat`（有 Python 时会打开本地页面）
- 也可把站点「安装」为 PWA，离线继续玩

当前页面：https://hxiaolz23.github.io/no-guess-minesweeper/

## 难度

- 经典：初级 9×9/10、中级 16×16/40、高级 16×30/99
- 无猜密度：疏雷、匀雷、密雷（雷更疏，推理链更好构造）
- 自定义宽、高、雷数（过大棋盘会自动压到可构造范围）
- 每日挑战与种子链接：同一天、同一个链接是同一局
- 教学关：单格定雷、数字已满足、1-2-1、1-2-2-1

## 模式

- 练习：计时，可提示、可撤销
- 竞速：百分秒计时，关闭提示和撤销
- 禅：不计时，踩雷不会结束，随时可撤销

## 操作

- 左键翻开，右键或长按插旗，双击 / 中键展开
- 触屏可切换「翻开 / 插旗」，双指缩放；大棋盘可拖移
- 方向键移动，空格翻开，F 插旗，Z 撤销，Y 重做，P 暂停，H 提示

## 其他

- 提示只给出下一步能确定的格子，并可标出短推理链；不直接公布答案
- 可标出安全格或雷概率；分析按钮会写出当前还有多少格不能唯一确定
- 本地记录胜率、最佳时间、3BV、3BV/s、CPS，并可复盘、导出进度、下载棋盘图
- 主题：柔和、经典、暗色、像素；另有色盲配色
- 打开网页时会读 `version.json`；有新版本会提示（`file://` 本地下载包会跳过）

## 可选在线（B 档）

默认**不依赖服务器**。配置同步端点后可启用：

- **云备份**：设置里填写端点 + 同步密钥，上传 / 拉取 settings+stats；冲突可选较新覆盖或保留本地
- **每日榜**：通关「每日挑战」时尝试提交；统计页可刷新榜。失败不影响游玩
- 示例 Worker 与接口说明见 [`cloud/README.md`](cloud/README.md)
- 本地自测：打开 `#mockCloud=1` 用浏览器存储模拟云端

## 不做

- **不做实时对战。** 同一局面比速度请用分享链接或种子局。
- 不做强制账号体系；六边形 / 三维等变体不在当前范围。

## 发布与维护

本仓库按**低频维护**来规划：优先保持静态可玩、可离线。

交付方式：

1. **OpenShip / 静态托管**网页版（可选再挂 Worker 做备份与榜）
2. **下载到本地**直接打开（现有 `index.html` / PWA；在线功能自动降级）
