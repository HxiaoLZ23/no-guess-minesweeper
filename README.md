# 无猜扫雷

打开就能玩的无猜扫雷。每一局都由约束求解**直接构造**出一条完整推理链：首击及其周围没有雷，并且独立求解器能只靠可见数字走完全程。不是先随机埋雷再反复丢弃。

## 启动

- 双击 `index.html`
- 或双击 `start.bat`（有 Python 时会打开本地页面）

在线：https://hxiaolz23.github.io/no-guess-minesweeper/

## 难度

- 经典：初级 9×9/10、中级 16×16/40、高级 16×30/99
- 无猜密度：疏雷、匀雷、密雷（雷更疏，推理链更好构造）
- 自定义宽、高、雷数（最大约 50×40）
- 每日挑战与种子链接：同一天、同一个链接是同一局
- 教学关：单格定雷、数字已满足、1-2-1、1-2-2-1

## 模式

- 练习：计时，可提示、可撤销
- 竞速：百分秒计时，关闭提示和撤销
- 禅：不计时，踩雷不会结束，随时可撤销

## 操作

- 左键翻开，右键或长按插旗，双击 / 中键展开
- 触屏可切换「翻开 / 插旗」，双指缩放格子
- 方向键移动，空格翻开，F 插旗，Z 撤销，Y 重做，P 暂停，H 提示

## 其他

- 提示只给出下一步能确定的格子，不直接公布答案
- 可标出安全格或雷概率；分析按钮会写出当前还有多少格不能唯一确定
- 本地记录胜率、最佳时间、3BV、3BV/s、CPS，并可复盘、导出进度、下载棋盘图
- 主题：柔和、经典、暗色、像素；另有色盲配色
- 可安装为离线页面（PWA）

实时对战、六边形 / 三维棋盘、账号云同步没有做。同一局竞速请用分享链接；换设备用「导出进度」。
