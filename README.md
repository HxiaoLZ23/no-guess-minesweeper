# 无猜扫雷

柔和界面的无猜扫雷：开局后生成的局面可用纯逻辑通关，不必靠猜。

## 启动

任选其一：

1. **最简单**：双击打开 `index.html`
2. Windows：双击 `start.bat`（若系统有 Python，会起本地服务并打开浏览器）

## 难度

| 难度 | 规格 |
|------|------|
| 简单 | 9×9，10 雷 |
| 中等 | 16×16，40 雷 |
| 困难 | 16×30，99 雷 |

## 操作

- 左键：翻开
- 右键 / 长按：插旗
- 双击已翻开数字：当周围旗数等于数字时，翻开其余格
- 中间圆形按钮：新游戏

## 技术说明

首次点击后，程序会反复随机布雷并用逻辑求解器（基础规则 + 子集推理 + 前沿 CSP）校验，直到得到可无猜通关的局面。
