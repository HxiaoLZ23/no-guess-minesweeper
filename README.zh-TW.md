## 怎麼玩

- **電腦**：左鍵翻開，右鍵標旗。數字周圍旗數已滿足時，按兩下或中鍵該格，可翻開其餘鄰格。
- **手機**：點按翻開，長按標旗。可切換「翻開 / 標旗」，雙指縮放。
- **鍵盤**：方向鍵移動，空白鍵翻開，F 標旗，Z 復原，H 提示。
- 開啟後先在首頁選擇模式。練習、競速、禪再進入下一頁選擇盤面。闖關和教學關卡各自有一頁。

## 難度與模式

- 經典：初級、中級、高級。
- 疏雷、勻雷、密雷的雷數較少，便於練習。
- 練習先選擇雷數較少的盤面，再進行經典雷數。競速只記錄經典三檔和每日挑戰。禪模式不計時，尺寸可自訂。
- 闖關自 8×8 起，依 8×8、8×9、9×9、9×10 的順序增大，直到 18×18。
- 教學關卡可展開完整解析。
- 練習可以使用提示、復原和暫停。
- 競速在倒數計時後開始。無提示，不可暫停，並記錄點擊次數與最佳用時。
- 禪模式不計時。踩雷不結束對局。
- 復盤可暫停，並依 0.5×、1×、2×、4× 播放。

## 本機與可選雲端

預設完全離線。可在設定中匯出或匯入進度。

若設定了同步端點，還可進行雲端備份和每日榜。失敗不影響遊戲。部署說明見 [`cloud/README.md`](cloud/README.md)。

## 啟動

- 開啟 `index.html`，或使用上方連結。
- 也可安裝為 PWA，離線使用。

不做即時對戰。比較用時請使用分享連結。
